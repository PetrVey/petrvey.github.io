        <a href="https://github.com/PetrVey/pyTENAX" target="_blank">pyTENAX</a>
      </h3>
      <p class="subtitle is-6">Python &nbsp;·&nbsp; MIT License</p>
      <p>
        A Python implementation of the TENAX model — a temperature-dependent, non-asymptotic statistical framework
        for predicting extreme sub-hourly precipitation intensification based on temperature shifts (Marra et al., 2023).
        The package also includes a simplified SMEV (Metastatistical Extreme Value) class and a Weibull tail hypothesis test.
      </p>

      <h3 class="title is-4">
        <a href="https://github.com/PetrVey/pyErosivity" target="_blank">pyErosivity</a>
      </h3>
      <p class="subtitle is-6">Python &nbsp;·&nbsp; MIT License</p>
      <p>
        A Python package for calculating rainfall erosivity (Re) from precipitation data at 5-minute and 60-minute
        temporal resolutions. Follows the methodology of Rogler &amp; Schwertmann (1981) and Fischer et al. (2018),
        using the Imax30 threshold to identify erosivity events.
      </p>
